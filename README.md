# plan-learn-linux-on-mac

The plan for learning operator-level Linux while working on macOS, using a
disposable colima VM.

This repository holds the reasoning only: **[`docs/design.md`](docs/design.md)**
— why the plan is shaped the way it is, what was rejected, and where the
boundaries are.

The work itself happens in
**[`learn-linux-on-mac`](https://github.com/hypatia-tile/learn-linux-on-mac)**:
the roadmap, the lab setup procedure, the service being grown, and one issue
per step.
